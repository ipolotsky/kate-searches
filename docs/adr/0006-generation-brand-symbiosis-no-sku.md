# ADR-0006 — Генерация: симбиоз «инфоповод × бренд», без SKU-слоя

**Статус:** accepted · **Дата решения:** 2026-06-30.

В контексте генерации черновика поста из отобранной новости,
сталкиваясь с тем, что связать инфоповод с клиентом ценно, но продуктового каталога у нас нет,
мы выбрали **черновик-симбиоз «инфоповод × бренд»** — новость органично вплетается через профиль бренда (позиционирование, экспертиза, угол) с явным полем `brand_tie_in`,
и отвергли привязку к каталогу/SKU (нет продуктового слоя в MVP, дорого поддерживать, не нужно для контент-задачи),
чтобы выдавать органичную брендовую статью с SEO/AEO без продуктовой интеграции,
принимая как компромисс отсутствие прямой товарной привязки (product-tie-in) — это роадмап.

Схема и промпт драфтинга — [AI-пайплайн §4](/ai-pipeline-prompts.md).
